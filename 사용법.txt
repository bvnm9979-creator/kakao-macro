================================================
 카카오톡 자동 발송 매크로 사용 설명서
================================================

[ 1. 초기 셋팅 방법 ]
1. 압축을 푼 폴더(kakao_macro.exe 가 있는 폴더)를 엽니다.
2. 'kakao_macro.exe' 파일을 더블 클릭하여 1번만 실행합니다.
3. 잠시 후 폴더 안에 [ setting.txt ] 와 [ message.txt ] 파일이 자동으로 생성됩니다.
4. 일단 실행된 검은 창은 우측 상단의 X를 눌러서 잠시 꺼둡니다.

[ 2. 설정 수정하기 ]
1) 사진 경로 및 시간 설정:
   새로 생긴 'setting.txt' 파일을 열어주세요.
   - 시간대: 발송을 원하는 시간을 14:30,15:00 처럼 적어주세요.
   - 채팅방개수: 카톡 채팅목록 맨 위에서부터 몇 개의 방에 보낼지 숫자를 적어주세요.
   - 이미지경로: 전송할 진짜 사진 파일에 마우스 오른쪽 버튼을 클릭하여 [경로 복사]를 누른 뒤, 이 곳에 붙여넣기 하세요. (예: "C:\바탕화면\광고.jpg")
   (작성이 끝났으면 파일 - 저장을 누르고 끕니다)

2) 메시지 내용 설정:
   새로 생긴 'message.txt' 파일을 열어주세요.
   여기에 카톡에 전송할 메시지를 자유롭게 작성합니다. (줄바꿈 가능)
   (작성이 끝났으면 파일 - 저장을 누르고 끕니다)

[ 3. 진짜 발송 시작하기 ]
1. PC 카카오톡을 켜고, 채팅 목록을 엽니다. (맨 위에서부터 매크로가 순서대로 내려갑니다)
2. 'kakao_macro.exe'를 더블 클릭해서 켭니다.
3. 끝입니다! 검은 창을 끄지 않고 그대로 두시면, 정해진 시간마다 알아서 카톡 채팅방을 열어 1)사진 전송 후 2)메시지를 발송합니다.

[ 💡 최고 유용한 꿀팁! ]
매크로(검은 창)가 켜져 작동 중이더라도 끄지 마세요!
그냥 언제든지 'message.txt'나 'setting.txt'를 열어 내용을 수정하고 저장만 띡 누르면, 매크로가 실시간으로 알아채서 바뀐 내용으로 전송합니다.
